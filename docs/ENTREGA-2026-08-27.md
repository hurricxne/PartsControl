## 0. Lo primero: lo NUEVO desde la entrega anterior

### 0.a · Dependencia nueva — **esto no se puede saltar**

```bash
cd backend && pip install -r requirements.txt      # entra `tzdata`
```

`tzdata` sostiene el cálculo de la **hora de Chile** (`ZoneInfo('America/Santiago')`), que
esta entrega usa para decidir cosas de negocio: si un despacho «salió hoy», el semáforo
tributario de las guías por facturar y los días hábiles. En un servidor sin base de zonas
horarias del sistema (contenedores slim), sin este paquete el backend **no levanta**.
